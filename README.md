# SIMTAB — Sistem Informasi Tagihan

SIMTAB adalah aplikasi sederhana berbasis **Go** yang dibuat untuk membantu mengelola data tagihan secara terstruktur melalui terminal.

Aplikasi ini menyediakan beberapa fitur utama, yaitu:

* Menambahkan data tagihan
* Menampilkan seluruh data tagihan
* Membayar tagihan
* Melihat statistik tagihan
* Mengubah data tagihan
* Menghapus data tagihan
* Searching berdasarkan nama, nominal, jatuh tempo, kategori, dan status
* Sorting berdasarkan nama, nominal, jatuh tempo, kategori, dan status

Project ini menggunakan beberapa konsep dasar pemrograman, seperti **struct, array, procedure/function, sequential searching, binary searching, insertion sort, dan selection sort**.

Project dibuat sebagai implementasi pembelajaran dasar pemrograman menggunakan bahasa **Go (Golang)**.
